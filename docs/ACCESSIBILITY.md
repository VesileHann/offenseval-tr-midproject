# Accessibility

- Deck: `paper/Team10_MidProject.html`, self-contained, keyboard operable.
- Controls: arrows/space, Home/End, `F` full screen, `D` theme, `P` presenter.
- Semantic headings, tables, chart alt text, `aria-live` slide announcements, visible focus.
- Supports `prefers-reduced-motion` and `prefers-color-scheme`.
- Automated audit with `axe-core` (WCAG 2.1 A/AA): **0 violations**.
- PDF is a print rendering of the same HTML; tagged-PDF export is not available in Chromium.
