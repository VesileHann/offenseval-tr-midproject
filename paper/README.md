# Mid-project deck

- `Team10_MidProject.pdf` — submission file (14 pages: 10 talk + 4 Project Card appendix).
- `Team10_MidProject.html` — self-contained presentation (no external files, works offline).

## Controls

| Key | Action |
|---|---|
| → / Space / PageDown | Next slide |
| ← / PageUp | Previous slide |
| Home / End | First / last slide |
| F | Full screen |
| D | Dark / light mode |
| P | Presenter window (current, next, notes, timer) |

The HTML includes a progress indicator, focus-visible outlines, reduced-motion support,
semantic tables, chart alt text, and an `aria-live` slide announcement.

Accessibility audit: `axe-core` WCAG 2.1 AA — **0 violations**.
